# Pirate Enemies — Grok Imagine

Hyper-realistic **pirate enemy** characters for 2D and 3D, generated with Grok Imagine and wired into an animated combat showcase.

## Features

- **Gallery** — hero art and enemy roster (Captain Rourke, Lady Voss, 3D turnaround)
- **2D Arena** — canvas sprites with idle / walk / attack cycles
- **3D Deck** — Three.js billboard fighters with bob, sway, strike, and orbit camera

## Assets (Grok Imagine)

| File | Use |
|------|-----|
| `public/assets/pirate-enemy-hero.png` | Hero portrait |
| `public/assets/pirate-2d-idle.png` | Captain idle sprite |
| `public/assets/pirate-2d-attack.png` | Captain attack frame |
| `public/assets/pirate-2d-female-idle.png` | Lady Voss idle |
| `public/assets/pirate-3d-turnaround.png` | 3D model reference |
| `public/assets/pirate-battle-scene.png` | Battle backdrop |

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL, then switch between **Gallery**, **2D Arena**, and **3D Deck**.

## Build

```bash
npm run build
npm run preview
```
