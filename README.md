# Tide of Legends

A Zelda-like pirate adventure in the spirit of *The Legend of Zelda: A Link to the Past*, built as a full HTML5 canvas game.

## Play

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Controls

| Key | Action |
|-----|--------|
| Arrow keys / WASD | Move |
| Z / J | Sword |
| X / K | Bomb |
| Space / Enter | Talk / open chests / doors |
| I | Inventory |
| M | Map |
| Esc / P | Pause |

## Features

- Screen-based overworld (Coral Cay) with village, jungle, ruins, and fortress
- Blackreef Fortress dungeon with map, compass, and boss fight vs Captain Bones
- Sword combat, bombs, keys, hearts, potions, and treasure chests
- NPCs with dialogue, cuttable bushes, bombable rocks
- Procedural Web Audio music and SFX
- All visual assets generated with **Grok Imagine**

## Goal

1. Talk to Old Finn at the dock
2. Open the chest for the **Tide Cutlass**
3. Explore north — earn the **Skeleton Key** in the Ruined Watch
4. Buy bombs in Tide Village if needed
5. Unlock Blackreef Fortress and defeat **Captain Bones**
